# Obstacle Attack (Unreal Engine C++)

**A personal time to learn about C++ on Unreal Engine**
From what I noticed, there are differences between when using Unreal Engine to write C++ and pure low-level C++. Unreal Engine has tons of macro and longer compiled time comparing that to C++.
Please note, I am still learning about using C++ on Unreal Engine.

## 🕹️ Project Overview
This project contains part of the course that I found containing a simple C++ to create an obstacle game such as moving and rotating platforms.

## 💻 Technical Specs
Game Engine: Unreal Engine 5
Language: C++
Compiler: Visual Studio
